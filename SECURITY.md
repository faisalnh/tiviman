# Security policy

## Supported versions

Only the latest release receives fixes while Tiviman is at version 0.x.

## Reporting a vulnerability

Report privately through [GitHub private vulnerability reporting](https://github.com/faisalnh/tiviman/security/advisories/new). Don't open a public issue.

Useful reports include the Tiviman version, the Android version, and steps to reproduce with synthetic data. Don't send real playlist URLs, credentials, or MAC addresses; describe their shape instead.

Relevant areas include credential or playlist leaks (storage, logs, screenshots, intents, backups), requests sent to hosts the user didn't enter, redirect handling, and parser bugs in M3U, XMLTV, or provider responses.

You should get a first reply within 14 days.
